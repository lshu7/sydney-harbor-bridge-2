# 悉尼海港大桥 · 1923—1932

一个可交互的 3D 建造过程演示：用时间轴重现悉尼海港大桥如何在没有现代重型设备、
计算机建模和 GPS 的年代，靠悬臂法、缆索和人力把两半钢拱在 134 米高空合龙。

**在线浏览**：<https://lshu7.github.io/sydney-harbor-bridge-2/>

## 打开方式

直接用 Chrome、Edge 或 Safari 双击 `index.html` 即可。Three.js 已放在
`vendor/three.min.js`，不需要联网，也不需要构建工具。

> 如果浏览器对本地脚本有额外限制，可在项目目录运行：
> `python3 -m http.server 8000`，然后访问 `http://localhost:8000/`。

## 交互

- **时间轴**：拖动底部滑块，查看任意施工阶段
- **播放 / 暂停**：左下圆形按钮，或按空格键
- **旋转 / 缩放**：在画面上拖动、滚轮缩放
- **视角**：右上角「全景 / 拱顶 / 桥面」，以及「重播」
- **讲解条**：桌面端是画面上方一条横向说明带，手机端是顶部卡片，都位于拱顶上方，不会遮挡桥梁
- **直达某一进度**：在地址后加 `?t=0.85`（0–1），例如
  `index.html?t=0.85`，页面会停在该阶段便于截图或讲解

## 文件结构

```
index.html          页面与全部 UI / CSS
js/utils.js         几何合并、世界坐标显隐材质（shader discard）
js/bridge.js        参数化钢拱、吊杆、桥面、引桥、缆索、吊车、车流
js/environment.js   天空、水面、砂岩陆地、城市、道路、灯光
js/main.js          渲染循环、相机、时间轴、章节与统计 UI
vendor/three.min.js Three.js r128（本地）
```

## 实现要点

- **参数化桁架**：主拱不是手工模型，而是按抛物线拱轴逐跨生成上下弦、竖杆、
  斜杆和横向支撑，因此可以按进度“生长”。
- **Shader 显隐**：`makeRevealMaterial()` 把世界坐标注入标准材质，在片元阶段
  discard 掉尚未施工的区域，实现钢构从两岸向中间延伸的干净边缘。
- **悬臂与合龙**：两半拱的端点位置驱动爬行吊车和缆索端点；合龙时拱从
  “被缆索拉住”过渡到自承重，缆索淡出并在拱顶触发一次火花。
- **桥面顺序**：吊杆与桥面都从两岸向中间出现，与引桥自然衔接。
- **配色**：Hex 颜色在 `main.js` 中统一转成线性空间，配合 ACES tone mapping
  与 sRGB 输出，避免画面发白。

## 想调整时

- **桥的尺寸 / 比例**：`js/bridge.js` 顶部的 `B` 对象（主跨、拱高、桥面高度、
  桁架深度、面板数）。
- **时间轴节奏**：`js/bridge.js` 的 `update()` 中各处 `smoothRange(...)` 区间；
  章节文字在 `js/main.js` 的 `chapters` 数组。
- **颜色与光照**：`js/environment.js` 的灯光、天空与水面 shader；
  `js/bridge.js` 的材质颜色。
- **城市轮廓**：`js/environment.js` 的 `addCity()`，使用固定随机种子，
  每次加载布局一致。

## 史实说明

- 主跨 503 m，全长 1,149 m，拱顶高出海面 134 m，用钢约 52,800 吨，
  铆钉约 600 万颗，约 1,400 名工人参与，16 人殉职。
- 两半拱于 1930 年 8 月合龙，当时存在约 0.6 m 的偏差，用液压千斤顶校正。
- 两岸四座花岗岩塔楼是装饰性的，不承担结构荷载。
- 1932 年还没有悉尼歌剧院（1973 年建成），场景中的天际线按低层城市处理。
- 当年并非“纯手工”：已有蒸汽/电动绞车、气动铆钉枪和缆索吊车；缺少的是
  今天的重型吊装船、计算机分析与卫星定位。

> 这是一个风格化的叙事演示，不是结构力学仿真；钢拱的细部、施工顺序和
> 城市肌理都做了简化。
